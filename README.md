## About

Loupedeck software accompanies Loupedeck physical controllers for creative professionals. Map dials, buttons, and touch strips to Adobe Lightroom, Premiere Pro, Photoshop, Final Cut Pro, and hundreds of other creative applications for tactile, intuitive control over editing parameters. The software manages profiles, custom actions, and marketplace plugins for expanding device functionality.

## Common Problems & Limitations

- **Hardware Required** — Software only functions with Loupedeck physical controllers
- **Hardware Investment** — Loupedeck devices cost $200-$400+
- **Application Coverage** — Some niche applications require custom profile creation
- **Driver Dependencies** — Stable operation requires keeping drivers updated with OS updates
